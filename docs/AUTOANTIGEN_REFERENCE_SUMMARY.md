# Autoantigen Reference Summary

This document summarizes the curated autoantigen panel used in the broader AtomicGuard molecular mimicry workflow.

Scope note:

## Why This Matters

The autoantigen panel defines biologically relevant targets for sequence and structure-level analysis in vaccine-associated autoimmune risk modeling.
